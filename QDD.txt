1. What are sessions and cookies?
   - Cookies. A file that stores user data in the browser
   - session. A store for user data on the server side. 

2. How do they work?
   User logs in → server creates a session → sends a cookie with session ID to browser.
   Browser sends cookie with every request.
   Server looks up session ID → restores user info.
